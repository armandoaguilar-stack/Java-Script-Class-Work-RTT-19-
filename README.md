Getting Started:
Make sure you have a GitHub account
Make sure you have Google Chrome installed 
Make sure you have Visual Studio Code installed to be able to run through the code in detail. 

Prerequisites:
Windows 10 or newer version
8GB of random access memory (RAM)
5GB of free hard drive space memory

Installation


Download VS Code at https://code.visualstudio.com/download
Alternative: Use web browser Visual Studio Code at https://vscode.dev/
Clone the GitHub repo at https://github.com/armandoaguilar-stack/Java-Script-Class-Work-RTT-19-

Usage:
SAB 307 can be used to understand inline, internal and external styles used in HTML. 
Make sure to scroll through each navigation tab to fully understand how it works.
